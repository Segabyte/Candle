# Life — LifeQuest

Working folder for **LifeQuest: Learn Life One Move at a Time** — an original
educational board game where every move teaches the player something about
life, on a default Life Skills track or on a topic each player chooses for
themselves, playable solo against AI opponents.

## Contents

| File | What it is |
|---|---|
| [`lifequest.html`](lifequest.html) | **The playable game.** Open it in any browser — no build step, no server, no network. |
| [`GAME-README.md`](GAME-README.md) | How to play, how to add topic packs, how to wire up a live AI generator. |
| [`LIFEQUEST-AI-PROMPT.md`](LIFEQUEST-AI-PROMPT.md) | The full game design prompt — paste into an AI to generate the game. The *Visual Direction* section also works standalone as an image prompt. |

## Origin

Grew out of [`ideas/idea-002-life-learning-board-game.md`](../ideas/idea-002-life-learning-board-game.md).

## Ground rule

Everything here must be **original** — original board layout, space names,
card wording, logo and artwork. Existing board games are inspiration for the
physical *experience* only; no artwork, names, logos, wording or layouts are
copied from them.
