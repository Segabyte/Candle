# Ideas

A scratch space for ideas about the app, solutions, and future business
directions. Nothing here is a commitment — it's a place to capture thoughts
before they're lost.

## How this folder works

- One file per idea: `idea-001-short-slug.md`, `idea-002-...`, and so on.
- Numbers are assigned in the order ideas are captured, not by priority.
- Ideas are written down as stated first; refinement happens later in the
  same file under **Notes / Refinements**.
- Anything that graduates into real work moves to `ROADMAP.md` or its own
  `FEATURE-*.md` spec at the repo root, with a link back here.
